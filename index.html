features

Moxi does the annoying parts
so you don't have to.

Mod managers should not need tutorials or accounts. Moxi handles loaders, dependencies, and file placement so you can get to playing.

Finds your games automatically

Moxi scans all your Steam library folders across every drive. You don't point it anywhere, it knows where everything is for you.

Handles mod loaders too

If a game needs BepInEx, RROML, or MelonLoader, Moxi offers to install it first. No separate downloads, no config files, no guessing.

Dependency resolution

When a mod requires another mod, Moxi catches it and shows you the full install chain before touching anything. Nothing breaks silently.

Enable and disable without uninstalling

Toggle mods on or off whenever you want. Disabled mods stay on disk and are ignored by the game until you flip them back.

Recently played

Games you launch through Moxi are tracked so your most-used ones are always one click away. Less hunting, more playing.

Automatic update checks

Moxi checks for new versions of itself on startup and tells you when one is available. No background processes, no surprises.

how it works

Up and running in about a minute.

No wizard, no account, no API key. Download -> Open -> Play.

01

Download and run

Grab the installer from GitHub and run it. No extra software, no unusual permissions. It just opens.

02

Your games appear

Moxi scans your Steam folders on first launch. Supported games show up in the sidebar, ready to go.

03

Pick a mod, click install

Browse the mod list for a game, hit install, and Moxi handles the rest: loader, dependencies, placement, everything.
